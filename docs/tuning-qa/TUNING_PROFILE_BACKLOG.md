# Tuning profile backlog

## How priorities were chosen

This is a **qualitative owner/workshop planning order**, not a market-share ranking. No registration totals, sales statistics, workshop job counts or search volumes were supplied. Dutch-market and workshop relevance therefore mean the owner's stated vehicle priorities, practical van use, and reuse across related model families; they are not claims about measured popularity.

Evidence comes from the four [live RDW cases](runtime/live-rdw-identities.json), the fixed 64 normal-ICE inputs in the [runtime coverage report](runtime/runtime-coverage.md), and the owner's requested family list. The 56 non-public inputs are plausible synthetic model/engine regression contexts. Their generated source stock values and years are not independently verified factory specifications.

Priorities favor owner acceptance cases, generic later Stages, ambiguity between existing sources, and source gaps shared by several models. Existing canonical figures remain useful labelled estimates. A high rank does not authorize a new NoordTune target or a new public SEO page.

## Completion requirements for any family

1. Record manufacturer stock facts and the exact applicability boundary: model family, generation, fuel, displacement, registered output and useful engine/variant evidence.
2. Record each Stage's independent source, conditions and uncertainty. A Stage 1 source is not proof of Stage 2/3 output.
3. Keep external tuner claims, catalog estimates and measured NoordTune results distinct. Preferred NoordTune targets need an explicit owner/workshop decision.
4. Add positive runtime fixtures and wrong-family, displacement, generation and powertrain controls. Preserve the four existing live owner regressions.
5. Keep output, ECU/access status and commercial category independent. Generic and canonical data must never establish a confirmed ECU lock or transmission.
6. Retain numeric fallback scenarios with clear ranges until better evidence exists. Add public SEO pages only through a separate publication decision.
